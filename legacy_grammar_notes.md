# Legacy Grammar Notes (Dictionary v2.1)

These notes were stored as rows in the old Excel dictionary. They predate the
Codex of Dwarven Grammar (4th Edition), which supersedes them; they are kept
here for historical reference only.

## verb

```
-ok/-az, The verb suffix MUST be attached to the subject, as well as with the correct time prefix! "The Starbreakers Protect the Kal'Varak"

Time Prefix + Subject + Verb Suffix  ,  Verb  , rest of sentence

Da Aina'Kornazkarumm'az akvel da Kal'Varak
```

## adjective

```
-mos/-os/-rum, nouns come before adjectives.
 Example: "He is in the Red House"

noun - adjective, ('os denotes adjectives, describer of noun)

Ka yol-mer nir da gord ardoth'os
```

## adverb

```
Suffix: 'a / 'os
The adverb suffix can modify both verbs and adjectives, for example:
"Yno'lon'az strol vlokon'a"
 - she walked quick'ly
```

## pronouns

```
Prefix: Karen-/Vo-/Yol-/Va-
Suffix: -Koss/-Loss-/Edos
 
Examples:

My: Vo'Tha, Vo'K
Our: Yol'Thamar
Your: Othok'koss
Her: Lon'edos
His: Vo'Ka
Their: Korth'Edos
```

## time_tense

```
Past: Yno-/Yllor-
Present: Aina-/Khirn-
Future: Enn-/Ea-
Perfect: -Nairon-/-Naerk-
```
